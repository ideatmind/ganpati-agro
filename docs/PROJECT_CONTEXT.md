# Project context

Shri Ganpati Agro Producer Company Ltd. provides a bilingual, accessible registration system for farmers. A ₹500 captured payment creates the farmer and active membership immediately. Public users, employees, farmer referrers, managers, and super administrators share one application with role-specific access.

## Current release

- Public and employee-assisted farmer registration with all legacy farmer and plot fields.
- Razorpay order-based checkout, signature verification, webhook reconciliation, and device-generated receipt.
- Mobile number + password accounts.
- Unique mobile number and Aadhaar per person.
- Farmer and employee referral dashboards with a default 10% commission.
- Offline referral payouts recorded by management and visible to recipients.
- Managers edit farmer records; employees may edit only through short-lived grants.

The authoritative rules live in `BUSINESS_RULES.md`; dated decisions live in `DECISIONS.md`.
