# Communication

Farmer-facing content uses Marathi first with concise English support for important actions, amounts, and payment states. Messages must be calm, specific, and independently confirmable.

Key states are: **Registration saved**, **Payment pending**, **Payment received — processing**, **Membership active**, and **Payment failed — retry available**. Color is always paired with an icon or label.

The initial release generates on-screen confirmation and a printable receipt. SMS and WhatsApp notifications are outside the current release.
